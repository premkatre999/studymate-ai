# Contributing

Thanks for helping improve StudyMate AI.

1. Open an issue describing the problem or improvement.
2. Create a branch such as `feature/readme-check` or `docs/demo-guide`.
3. Make a focused change and use a descriptive commit message.
4. Run the app locally and manually verify the changed behavior.
5. Open a pull request with a summary, test steps, and screenshots for UI changes.
6. Ask a teammate to review it before merging.

Never commit `.env` files, access tokens, passwords, or private repository data.

## Suggested starter tasks

- Improve a checklist explanation.
- Add a URL parsing test.
- Add a README screenshot.
- Test behavior for a nonexistent repository.
- Improve mobile layout or keyboard accessibility.
- Add automated tests and a GitHub Actions workflow.
