## How we collaborate

1. Open an issue before starting a discrete task.
2. Use a feature branch for changes.
3. Make small commits with descriptive messages.
4. Open a pull request and ask another teammate to review it.
5. Link the issue in the pull request.
6. Record a short note about the decision and any trade-off.

## Demo walkthrough (about 2 minutes)

1. Explain the problem: reviewers need to understand a repository quickly.
2. Paste a public GitHub repository URL and run the scan.
3. Explain the checklist score and show at least two evidence-based recommendations.
4. Show the contributor sample and explain its limitations.
5. Answer one practice question using a real part of this codebase.
6. State one known limitation and the next feature the team would build.
